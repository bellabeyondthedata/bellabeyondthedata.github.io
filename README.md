# Bella Beyond the Data — Starter Website

This folder is a simple, responsive personal career website ready for GitHub Pages.

## Files
- `index.html` — all page content
- `styles.css` — colors, layout, fonts, responsive design
- `script.js` — mobile menu + current year
- `resume.pdf` — add your actual resume with this exact filename when ready
- `images/` — add your personal photos here

## First things to replace
1. In `index.html`, replace:
   - `YOUR_EMAIL_HERE`
   - `YOUR_LINKEDIN_URL_HERE`
   - `YOUR_GITHUB_URL_HERE`
2. Replace the placeholder portrait and life-section image boxes with your own images.
3. Add your actual resume to this folder as `resume.pdf`.
4. Replace placeholder project links (`href="#"`) with real project pages or GitHub links.

## How to publish with GitHub Pages
1. Create a GitHub repository named:
   `YOURUSERNAME.github.io`
2. Upload all files from this folder to the repository root.
3. Commit the files.
4. Visit:
   `https://YOURUSERNAME.github.io`
5. If it does not appear immediately, open:
   Settings → Pages
   and make sure the site is publishing from the main branch.

## Custom domain later
Once you have `bellabeyondthedata.me`, add it in:
Settings → Pages → Custom domain

GitHub will tell you what DNS records to add at your domain provider.

It is intentionally simple so we can iterate without rebuilding the structure.
